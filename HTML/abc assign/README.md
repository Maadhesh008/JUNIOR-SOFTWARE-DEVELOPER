# ABC Challenge Group Assessment

Open `index.html` in a browser to view the project.

## Rubric coverage

- Three ABC picture cards are included in the HTML.
- `style.css` is linked and sets a grey background.
- `h3` headings default to green, three headings use the blue class, and one heading is red.
- `script.js` is linked and makes every `h5` cycle through green, blue, and red on click.
- Keyboard activation is also supported for accessible repeatable colour changes.

## GitHub task

Create a GitHub repository for this folder, add team members as collaborators, and create project-board cards for the HTML, CSS, JavaScript, and review tasks.
