# Field Notes Blog Site Group

A three-page group blog site for the TIFC2DEV-AD-07 Blog Site Lab.

## Pages

- `index.html` - Home page with topic content, images, and latest stories
- `about.html` - Group purpose, authors, and values
- `contact.html` - Fake email, phone number, studio hours, and contact form

## Rubric coverage

Every page includes the sticky navigation menu and shared footer with the project name, authors, and fake contact email. `style.css` provides responsive editorial styling and `script.js` adds the mobile menu and contact form feedback.

## GitHub project setup

Create or reuse the `TIFC2DEV-SDPF3 SCRUM Project Simulation` repository, open this folder in VS Code, and publish it through Source Control. Add team members as collaborators, then create backlog cards for Home, About Us, Contact Us, responsive styling, testing, and review.
